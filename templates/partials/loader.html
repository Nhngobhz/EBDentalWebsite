{# Site-wide loading overlay. Covers the page while it's still loading and again while the browser is navigating away, so a slow store-api fetch never leaves the visitor staring at a blank/frozen page. The mark is the EB "spinning tooth" logo drawn inline as SVG rather than as a .gif: it stays crisp at any size, weighs ~1KB, picks up the theme colours, and can be stilled for prefers-reduced-motion. To use a real animated file instead, swap the and nothing else needs to change. Styles live in css/loader.css. #}
